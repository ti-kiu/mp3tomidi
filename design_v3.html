Does it support drums?

Basic Pitch is primarily designed for melodic and harmonic instruments (piano, guitar, vocals). While it will attempt to transcribe percussion, results may vary depending on the frequency spectrum of the kit.

How does it run without a server?

We utilize TensorFlow.js and WebAssembly (WASM) to download the machine learning weights to your browser's cache once. All subsequent calculations happen on your device's CPU or GPU via WebGL.

Is there a CLI version?

Yes. The core library is open-source. Developers can access the MIDI-CORE CLI on GitHub to integrate this engine into automated server-side pipelines or local batch processing workflows.
